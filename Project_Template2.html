UNR Parking Locator

A class project built to help drivers find open parking spots on campus.

Class Project UNR

Overview

Designed as a one-week "Smart Cities" prototype, this system upgrades UNR’s current parking infrastructure by pushing real-time space availability to a web interface, saving drivers from manually scanning for LED indicators. The project leverages an ESP-NOW wireless network between ESP32 microcontrollers to connect ground stations to a central node without running physical wires. Because the ESP32 only features two I2C controllers, driving four distinct OLED displays required a creative software workaround: dynamically reallocating the I2C pins during runtime to hot-swap communications between the screens, resulting in a seamless, glitch-free visual update.
